# 2026-10-02 최종 개선 실험

목표는 리더보드 비독성 F1 0.85 이상이다. OOF→리더보드 +0.004는 한 번 관찰된 차이여서 고정 보정값으로 사용하지 않는다. 실제 평가셋 라벨은 없고, 모델의 기대 F1은 실측 점수가 아니다.

1. 클로드의 16개 모델/OOF/3차 Output 재현. 파생 `final_stack_lr`를 다시 base 입력에 넣지 않는다.
2. 기존 full OOF와 신뢰할 수 있는 새 6개 입력을 사용해 동일한 3개 메타 분할에서 비교. 임계값 주변 강조와 규제 LR 비교. base OOF 재사용의 간접 누수 한계를 명시한다.
3. 8,349행 전체 재학습. 기존 4-seed Chemprop, 4-seed LightGBM과 정확히 복원한 9개 GBDT 평균, CatBoost·Mordred·SVM·RF/ET/선형/MLP/kNN. 테스트 예측만 갱신한다. 자체 학습 점수를 성능 증거로 쓰지 않는다.
4. 잠근 outer fold에서 3종 base의 inner OOF를 새로 생성. outer 검증 라벨이 어떤 base 학습에도 포함되지 않도록 확인한다. 60% 학습 4-fold 평균과 80% 학습 재학습을 동일 outer 평가행에서 비교한다. 기존 글로벌 하이퍼파라미터 탐색이 이 fold를 봤다는 한계가 있다.
5. 기존 ChemBERTa는 고정 임베딩 실험만 있으므로 마지막 2개 encoder 층을 독성 라벨로 미세조정한다. 5-fold, 각 8 epochs, 사전에 고정한 마지막 3개 epoch 예측 평균. outer 점수로 best epoch를 고르지 않는다. 캐시 모델을 오프라인으로 GPU에서 사용한다.
6. 개선 후보의 영향/변경 행/형식을 확인하고 별도 제출용 CSV 작성. 현재 3차 Output과 원본은 보존한다. 제출은 하지 않는다.

단순 학습량 증가의 AUC 개선을 F1 증가로 확정하지 않는다. 높은 전역 AUC만으로 채택하지 않고, 비독성 F1과 기존 cutoff 주변 0.35~0.50 band 진단을 함께 본다. 강제 구조 라벨 복사, 자기 스태킹, 검증 라벨로 best epoch 선택, 리더보드 차이의 고정 가산은 적용하지 않는다.

전체 재학습 채택 기준(outer 평가 전 고정): refit의 F1이 fold 평균보다 0.003 이상 높으면 전체 refit, -0.002~0.003이면 50% 결합, -0.002보다 낮으면 기존 CV 예측을 유지한다. 단일 holdout 표본오차가 있으므로 paired bootstrap 구간도 기록한다. ChemBERTa 추가 실험은 24 epochs, 4가지 SMILES 표현을 학습과 TTA에 사용하며 stereo canonical round-trip을 검사한다.

강화 ChemBERTa 채택 기준(전체 OOF 완료 전 고정): 기존 16개 입력+C=.01에 1개 모델만 추가. 동일 3개 메타 분할에서 평균 F1 +0.001 이상, 모든 분할에서 비하락, 고정된 경계 band AUC +0.002 이상일 때 채택한다. 이 메타 비교는 base OOF 재사용의 간접 누수 한계를 공유한다.

작은 잎 LightGBM 확인: 기존 3-model nested 실험에 사전에 선택했던 leaf31/min_child8을 추가해 비교한다. 동일 outer/inner 분할이며 새 inner OOF부터 생성한다. 총 F1 +0.002 이상과 경계 band AUC 개선이 함께 나오면 추가 모델 방향을 채택한다. 모델의 글로벌 사전 선택 편향 한계는 남아 있다.

최고 실측 0.8393의 20개 확률 입력에 새 계열을 더하는 raw-logit 결합을 기존 순위 결합과 구분해 검증한다. CP만 추가, CP/CatBoost/Mordred 추가, 임베딩 SVM까지 추가와 약한 규제 대안을 같은 3개 meta 분할로 비교한다. 평균 F1 +0.001 이상·모든 분할 비하락·경계 band AUC 상승을 채택 기준으로 고정한다.
