## 선택 결과

기존 실제 최고 제출본의 20개 입력에 Chemprop, CatBoost, Mordred LightGBM, ChemBERTa/MoLFormer SVM을 추가했다. 순위로 바꾼 입력 대신 **확률의 logit**을 로지스틱 모델에 넣어 확신 정도를 보존했다. C=0.1, 3-seed × 5-fold 메타 모델 15개의 예측을 평균한다. base 모델의 기존 80% 학습 예측과 전체 8,349행 재학습 예측은 **50%씩** 섞었다.

임계값은 inner meta CV에서 고른 중앙값 **0.421868092**다. 양성 예측 **557행**, 현재 루트 Output과 **10행**, 실제 최고 제출본과 **14행** 다르다. 제출 후보 파일의 SHA-256과 보존 검사는 [validation.json](validation.json)에 있다.

숨은 정답으로 확인한 새 F1은 없다. **목표 리더보드 F1 0.85와 내부 기준 0.846에는 아직 도달했다고 말할 수 없다.** 새 조합의 반복 meta CV F1은 0.835438이고, 평균 OOF에 고정 임계값을 적용한 F1은 0.835987이다. 이 둘은 서로 다른 계산이다. 최종 전량 학습 효과가 OOF에 추가된 값도 아니다.

## 리더보드와 클로드 로그 검수

읽기 전용으로 저장한 [리더보드 스냅샷](leaderboard_snapshot.csv)에서 서혁인의 11:34 제출은 **0.8393**, 13:38 제출은 **0.8377**이었다. 최고점 파일은 `09_임계값/2차_제출됨_백업.csv`이며 우리의 08_재개선 파일과 동일하다. 따라서 16개 순위 스택의 기대 F1 증가만으로 실제 개선을 인정하지 않고, 최고 실측 제출본을 출발점으로 삼았다. 보드에 기록된 제출 횟수와 전달된 로그의 회차가 달라 남은 횟수를 추정하지 않는다.

- 기존 16개 입력, OOF/test 스택, D=567을 재현해 현재 Output과 정확히 일치했다. `final_stack_lr` 같은 파생 스택은 입력에서 제외했다. 클로드의 `final_report.py`는 재실행 시 자신의 출력 캐시를 입력 후보에 포함할 수 있다.
- 기존 `blendlib.evaluate`의 nested 수치는 메타 모델과 임계값을 분리하지만 base OOF를 재사용한다. 다른 메타 학습 행의 base 모델에는 outer 검증 라벨이 포함될 수 있으므로 완전한 nested 평가가 아니다.
- 연결구조 라벨 복사는 적용하지 않았다. 제출값은 원래 규약으로 확인했고, 작업용 train의 반전된 label과 혼동하지 않았다.
- "학습량 증가 효과는 검증 불가능"은 너무 강한 주장이다. outer 행을 고정하고 inner 학습량을 늘려 방향을 비교할 수 있다. 실제 100% 학습 후 숨은 테스트의 점수는 알 수 없다.
- OOF→리더보드 +0.004나 기대→실측 +0.0027을 고정 가산하지 않았다. A=493은 공개 지표에 부합하는 양성 개수이며 분자별 정답을 알려주지는 않는다.

## 학습량 증가를 5개 outer fold에서 검증

LightGBM·복합 Tanimoto SVM·Chemprop 3종에 대해 base부터 새로 학습했다. 각 outer 검증 라벨은 어떤 base/meta fitting에도 들어가지 않았다. inner 4-fold OOF로 메타 모델과 임계값을 학습하고, 같은 outer 행에서 60% 데이터 모델들의 평균과 80% 데이터 재학습을 비교했다. 전체 8,349행 모두 outer 검증에 한 번씩 사용했다.

| 경로 | pooled F1 | AUC |
|---|---:|---:|
| fold 모델 평균 | 0.830791 | 0.893631 |
| outer train 전량 refit | 0.833757 | 0.893270 |
| 50% 혼합 | 0.832063 | 0.894213 |

refit F1 증가 **0.002966**, paired bootstrap 95% 구간 **[0.000059, 0.005771]**다. 고정 경계 band AUC는 0.50676→0.53703로 올랐다. 전체 AUC는 소폭 떨어졌다.

사전 규칙은 증가 >=0.003이면 100% refit, [-0.002,0.003)이면 50% 혼합, 그 미만이면 기존 fold 모델 유지다. 증가가 0.002966이므로 **50% 혼합**을 선택했다. 참고용 보정 기대 F1이 더 높은 100% 후보를 골라 버리지 않았다.

이 검증은 3개 모델의 60%→80% 학습량 비교이며 최종 25개 모델의 80%→100% 성능을 직접 검증하지 않는다. 하이퍼파라미터는 이전 전체 CV 탐색에서 골랐으므로 모델 선택까지 완전히 분리된 holdout도 아니다.

## 추가로 시도하고 제외한 방법

- 경계 sample weighting과 순위 스택 입력 확장: 반복 F1 +0.00087로 기준에 미달했다.
- leaf31 LightGBM 추가의 별도 nested fitting 비교: F1 0.833757→0.831426, 경계 AUC도 하락해 추가 확대 방향을 기각했다. 기존 최고 제출본에 포함된 입력 자체는 동결해 유지했다.
- ChemBERTa 지도 미세조정: 8 epoch OOF AUC 0.79583. 모든 encoder 층과 랜덤 SMILES를 쓴 24 epoch·4-view TTA·마지막 3 epoch 평균은 AUC 0.84527. 스택 기여는 F1 +0.000073, 경계 AUC -0.001293으로 제외했다. 기존 고정 임베딩 SVM은 유지했다.
- 랜덤 SMILES 27,828개 중 stereo round-trip이 달랐던 2개를 원문으로 되돌렸다. 제출 SMILES는 한 번도 변경하지 않았다. 검증 AUC로 최적 epoch를 선택하지 않았다.
