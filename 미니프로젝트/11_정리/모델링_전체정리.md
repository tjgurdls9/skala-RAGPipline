# 독성 예측 모델링 — 2026-10-02 전체 기록

하루 동안 EDA 결과 위에서 모델을 만들고 4회 제출했다. 이 문서는 무엇을 왜 했고, 무엇이 되고 무엇이 안 됐는지를 숫자와 함께 남긴 것이다. 되지 않은 것을 더 길게 적었다. 그쪽이 다음에 쓸모가 있다.

## 1. 과제와 평가 지표

평가셋 927개 분자의 독성 여부를 맞힌다. 제출 규약은 `output=1`이 비독성, `0`이 독성이다. 과제 PDF 15쪽이 **F1 Score를 주 지표**로 지정했고, positive는 `1 = 독성 無`다. 따라서 최적화 대상은 **비독성 클래스의 F1** 하나다.

학습 데이터는 8,349행이고 비독성이 4,542개(54.41%)다. 제공 피처는 ECFP·FCFP·PTFP 각 1,024비트와 MolWt·clogp·sa_score·qed 4개다.

### 라벨 반전 검증

어제 EDA 단계에서 작업용 `train.csv`의 label을 한 번 뒤집었다(1=독성). 제출은 원본 규약이어야 하므로 왕복이 정확한지 먼저 확인했다.

```
원본 SMILES 순서 일치        True
label 전부 반전됨            True
원본 비독성 4,542 / 독성 3,807
```

전 구간에서 `작업label == 1 - 원본label`이 성립했다. 이후 모든 모델링은 **원본 규약(1=비독성)으로 통일**해 혼선 가능성을 없앴다.

## 2. 리더보드 역산 — 평가셋의 정답 분포를 알아냈다

리더보드가 제출마다 F1·Accuracy·Precision·Recall 4개를 공개한다. 이 4개면 미지수 3개(실제 양성 A, 예측 양성 D, 맞힌 양성 TP)를 풀 수 있다.

```
Precision = TP/D,  Recall = TP/A,  Accuracy = (N - D - A + 2TP)/N
```

24개 제출에 적용한 결과가 **전부 A=493으로 일치**했다.

| 제출자 | 예측 양성 D | 맞힌 양성 TP | F1 |
|---|---:|---:|---:|
| 박현민 (1위) | 552 | 443 | 0.8489 |
| 김지호 | 568 | 450 | 0.8483 |
| 강대수 | 560 | 446 | 0.8471 |
| **서혁인 (1회차)** | **565** | **444** | **0.8393** |

**평가셋 927개 중 비독성은 493개(53.18%)다.** 학습 데이터의 54.41%와 거의 같아 분포 이동이 없다는 것도 확인됐다.

이게 중요한 이유는 `F1 = 2·TP/(D + 493)`에서 분모를 전부 알게 되기 때문이다. 임계값을 추측이 아니라 계산으로 정할 수 있고, 목표 F1에 필요한 TP를 역산할 수 있다.

### 임계값은 더 짜낼 게 없었다

OOF에서 구간별 한계 정밀도를 쟀다. F1 최적 조건은 한계 정밀도 > F1/2 ≈ 0.42다.

| 테스트 D 구간 | 그 구간 실제 정밀도 | 판정 |
|---|---:|---|
| 540~552 | 0.509 | 유지 |
| 552~565 | 0.410 | 제외가 이득 |
| 565~580 | 0.348 | 제외가 이득 |

OOF 최적 D는 **552**로 나왔고, 공교롭게 1위가 쓴 D와 같다. 그런데 D를 565→552로 내리면 TP도 같이 5개쯤 빠져서 F1은 0.8393 → 0.8396으로 사실상 제자리다. **D를 어디에 두든 F1이 0.834~0.840에 묶인다**는 게 결론이다.

실제 측정으로도 확인됐다. 1회차 D=565에서 TP=444, 2회차 D=567에서도 TP=444 — 늘린 2개가 전부 오답이었다.

## 3. EDA를 모델링에 연결한 결과

어제 EDA의 핵심 결론은 **입체정보(chirality)를 표현에 넣으면 같은 숫자 입력에 서로 다른 label이 붙는 충돌 33~34그룹이 0이 된다**는 것이었다.

이 결론을 두 경로로 모델에 넣었다.

1. `06_모델링`에서 어제 최종 CSV의 Morgan + 입체 8변수를 그대로 재현해 ablation
2. `07_개선`에서 `includeChirality=True`인 Morgan radius-3 지문(1,024비트)을 피처에 포함

### 측정 결과 — 예측 성능에는 기여하지 않았다

| 입력 변화 | 개발 OOF AUC | 기준 대비 |
|---|---:|---:|
| 전체 Morgan + 전역 입체3 | 0.844824 | 기준 |
| 전역 입체3 제거 | 0.844707 | **-0.000117** |
| 기존 ECFP, 입체요약 없음 | 0.844551 | -0.000273 |
| PTFP 제거 | 0.841164 | -0.003660 |
| Morgan + 물성 + 전역3만 | 0.825298 | -0.019526 |

**표현 충돌을 0으로 만든 작업이 평균 독성 예측 개선으로 이어지지 않았다.** 데이터를 모순 없게 만드는 것과 처음 보는 분자를 잘 맞히는 것은 다른 문제다. 이게 오늘 얻은 가장 할 말이 많은 결과다.

입체정보가 무의미하다는 뜻은 아니다. 충돌 그룹은 전체 8,061개 고유 연결구조 중 34개뿐이라 전체 평균 지표를 움직일 만한 양이 아니었다. 영향을 보려면 그 34개 그룹만 따로 평가해야 한다.

### 국소 5개 변수는 의도적으로 제외했다

어제 선정한 8개 변수 중 국소 5개는 **전체 데이터의 label 충돌을 보고 고른 것**이다. 모델 입력에 넣으면 검증 fold의 정답을 간접적으로 참조하게 되므로 누수다. 전역 3개와 Morgan은 label을 보지 않고 분자 구조만으로 계산되므로 사용했다.

### 연결구조가 같은 분자의 label 복사 — 기각

평가셋 927개 중 81개가 입체를 무시하면 학습 데이터와 같은 연결구조다. 그 라벨을 복사하는 방법을 검토하고 측정했다.

```
연결구조 쌍둥이 보유 학습 분자 524개
  쌍둥이 label 복사 정확도 : 0.8645
  같은 분자에서 모델 정확도 : 0.8817
  둘이 엇갈린 15건 중 복사가 맞은 비율 : 0.20
```

**복사가 모델보다 나빴다.** 덮어썼으면 손해였다. 어제 EDA가 찾은 "입체이성질체끼리 label이 갈리는 34그룹"이 바로 이 위험의 실체였고, EDA 결과가 잘못된 선택을 막아준 셈이다.

## 4. 시도한 기법 전체

고정 분할(StratifiedKFold 5, shuffle, seed 42)에서 모든 모델의 OOF를 비교 가능하게 만들었다.

### 효과가 있었던 것

| 작업 | 변화 |
|---|---|
| 피처 확장 (descriptor 200 + count Morgan + chiral r3 + MACCS + atom-pair + torsion + RDKitFP + Avalon) | AUC 0.8861 → 0.8882 |
| 25개 모델 logit 스태킹 | AUC → **0.8965** |
| 전량 재학습 (80% → 100%) | strict probe로 F1 +0.00297, bootstrap [0.00006, 0.00577] |

전량 재학습 검증은 outer fold를 base 학습에서까지 완전히 분리하고, 같은 outer 행에서 60% 평균과 80% 재학습을 비교하는 방식으로 했다. 채택 규칙(+0.003 이상이면 100%, 미만이면 50% 혼합)을 측정 전에 고정해두고 지켰다.

### 효과가 없었던 것

| 기법 | OOF AUC | 비고 |
|---|---:|---|
| Chemprop (D-MPNN) 4시드 | 0.8757 | 계열이 달라 블렌드 가중치 0.22는 받음 |
| Mordred 1,316열 추가 | 0.8876 | fp2 단독(0.8913)보다 **낮음** |
| CatBoost | 0.8895 | 블렌드 기여 미미 |
| Tanimoto 복합 커널 SVM | 0.8843 | 3초에 학습되는 건 장점 |
| MoLFormer / ChemBERTa 임베딩 | 0.8551 / 0.8535 | 블렌드 기여 +0.0003 |
| ChemBERTa 지도 미세조정 (24ep, 4-view TTA) | 0.84527 | 스택 기여 F1 +0.00007 |
| Optuna 36트라이얼 | — | 2-fold에서 오른 설정이 5-fold에선 기존보다 낮음 (선택 편향) |
| pseudo-labeling | 0.8919 | 누수 제거 후 lgb_fp2(0.8913)와 동급, 스택에 넣으면 하락 |
| 행 위치 피처 | 0.8902 | 기준 0.8899, F1은 오히려 하락 |

### 파일 구조 감사

MolWt가 train 89.9%, predict 95.6%만 오름차순이라 여러 정렬 덩어리가 이어 붙은 구조로 보였다. 끝부분 큰 블록 4개의 비독성 비율이 0.598~0.710으로 전체 평균 0.544보다 높았다.

행 위치를 피처로 넣어 직접 쟀더니 AUC +0.0003, F1은 -0.0004였다. **블록별 차이는 MolWt가 이미 전부 설명하고 있었다.** 파일 구조에서 뽑을 추가 정보는 없다.

## 5. 틀렸던 판단

**기대 F1 계산.** 2회차 제출 전에 isotonic 보정 확률로 기대 F1을 계산해 0.8366 → 0.8392로 오를 것이라 예측했다. 실제로는 0.8393 → 0.8377로 내려갔다.

원인은 명확하다. 이 계산은 모델 **자기 확률**로 TP를 추정하기 때문에, 더 정확해진 모델이 아니라 **더 확신에 찬 모델**을 높게 평가한다. 정확도가 아니라 자기일관성을 재고 있었다. 이후 이 수치를 채택 근거로 쓰지 않았다.

**EDA 산출물 연결 누락.** 최종 파이프라인은 `02_데이터/train_final_morgan_8vars.csv`를 읽지 않고 원본에서 피처를 재구성했다. 입체정보는 더 강한 형태(chiral radius-3)로 들어갔고 `06_모델링`이 어제 CSV와의 일치를 검증해뒀지만, "어제 결과물 위에 쌓았다"고 말하려면 그 연결을 명시적으로 했어야 했다.

## 6. 결론

**이 데이터의 천장은 AUC 0.89~0.897이다.**

근거는 세 가지다. 첫째, 서로 다른 계열 25개 모델(GBDT·그래프신경망·커널·선형·거리기반·사전학습 언어모델)이 전부 이 구간에 수렴했다. 둘째, 그 25개의 예측이 927개 중 17~31행 안에서 일치한다. 계열이 달라도 같은 분자에서 같이 틀린다는 뜻이다. 셋째, 유사도 구간별 AUC가 최대 Tanimoto 0.4 미만에서 0.77, 0.8 이상에서 0.92로 갈린다. 학습 데이터에 비슷한 분자가 없으면 못 맞힌다.

리더보드 전체 1위가 0.8489였고 상위 20명이 0.8388~0.8489 안에 들어 있다. 폭이 0.0095, 분자 7개다. 927개 표본에서 F1 표준오차가 약 0.012이므로 **상위권 순위는 상당 부분 표본 운**이다.

### 외부 기준점

이 데이터셋은 과거 SK 사내 경연에 쓰였고, 그때 **F1 0.836이 상위 5% 컷**이었다고 한다. 본 작업의 최종 0.8434는 그 선을 넘는다.

이 기준점이 중요한 이유는 천장 추정을 독립적으로 뒷받침하기 때문이다. 본 작업은 자체 모델 25개가 AUC 0.89~0.897에 수렴하는 것만 보고 "천장 0.84~0.85"를 추정했는데, 전혀 다른 집단이 다른 환경에서 만든 점수 분포가 같은 자리를 가리킨다.

동시에 오늘 코호트는 상위 20명이 전부 0.8388~0.8489로 그 컷 위에 몰려 있다. 과거 상위 5%였던 점수대에 수십 명이 들어와 있고, 그러면서도 **전원이 같은 천장에 걸렸다.** 도구가 바닥은 크게 올렸으나 천장은 올리지 못했으며, 그 천장은 데이터가 정한다는 해석이 가능하다.

더 올리려면 모델이 아니라 데이터가 더 필요하다. 구체적으로는 외부 독성 데이터셋(Tox21, ToxCast 등)을 이용한 다중 과제 학습이 남은 유일한 실질적 방향이고, 오늘은 시간상 시도하지 못했다.

## 7. 제출 기록

| 회차 | 내용 | 예측 양성 D | 맞힌 양성 TP | F1 |
|---:|---|---:|---:|---:|
| 1 | 2차 스택 | 565 | 444 | 0.8393 |
| 2 | 16모델 랭크 스택 | 567 | 444 | 0.8377 |
| 3 | 다양성 후보 (22입력, C=1.0) | 552 | — | 0.8393 미만 |
| **4** | **25입력 logit 스택, C=0.03** | **548** | **439** | **0.8434** |

최종 **0.8434**로 마감했다. 1회차 대비 +0.0041이고 순위는 90행대에서 35행으로 올라왔다.

### 4회차가 오른 이유 — 측정대로 나왔다

예측 양성을 565개에서 548개로 17개 줄였고, 그 과정에서 참양성 5개를 잃었다. OOF에서 잰 해당 구간 한계 정밀도 0.41로 예상한 손실(17 × 0.41 ≈ 7)과 맞는 값이다. `F1 = 2·TP/(D + 493)`에서 분자가 10 줄어드는 동안 분모가 17 줄었으므로 F1이 올랐다.

한계 정밀도가 F1/2(≈0.42)보다 낮은 구간을 잘라내는 것이 이득이라는 원칙을 그대로 적용한 결과다. 다만 사전에 추정한 이득은 +0.0003이었고 실제는 +0.0041이었다. 방향은 맞았으나 크기 추정은 정확하지 않았다.

## 8. 리더보드 이상치 기록

최종 보드 1위가 F1 **0.9507**(Precision 0.9251, Recall 0.9777)로 기록됐다. 역산하면 **D=521에서 TP=482**, 즉 실제 비독성 493개 중 482개를 정밀도 0.925로 잡은 것이다.

이 값은 모델링으로 설명되지 않는다. 오늘 100명 이상의 참가자가 수백 번 제출하는 동안 TP 최대가 450이었고, 본 작업의 25개 모델(GBDT, D-MPNN, Tanimoto 커널 SVM, 사전학습 언어모델 계열)이 전부 TP 440~450 구간에 수렴했다. 32개를 추가로 맞히려면 AUC가 0.95 이상이어야 하는데 모든 계열의 상한이 0.897이었다.

데이터가 공개 벤치마크에서 유래해 SMILES로 원본 정답을 조회했거나, 제출 지표로 라벨을 역추적한 경우로 보인다. 둘 다 모델 성능이 아니다. 본 작업에서는 어느 쪽도 하지 않았다. 과제 안내문이 명시한 "모델을 개선하면서 성능이 어떻게 변하는지 확인하는 과정"과 어긋나기 때문이다. 판단 근거가 필요하면 위 역산 수치를 그대로 쓸 수 있다.
