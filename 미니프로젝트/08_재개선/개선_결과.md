# 독성 예측 2차 개선 결과 · 2026-10-02

**[제출용 predict_output_서혁인.csv](제출용/predict_output_서혁인.csv)** · 927행, `SMILES,output`. 기존 1차 파일은 그대로 보존했고 제출하지 않았다. `output=1`은 비독성이다.

최종 선택은 **logistic_C0.1**이며, 전체 OOF AUC는 **0.89548**, 비독성 F1은 **0.83494**, 정확도는 **0.80920**다. 메타 학습 행에서 고른 임계값을 검증 행에 적용한 F1은 **0.83458**다. 기존 1차와 **32행**이 달라졌고 비독성 예측은 **565/927행**이다.

## 클로드 피드백 검토

- 랜덤 층화 CV를 주요 비교 기준으로 바꿨다. 랜덤 CV의 골격 공유 비율은 약 62%, 예측 입력은 67.6%여서 기존 골격 분리 평가보다 가까운 근사다. 실제 평가셋의 분할법이 확인된 것은 아니다.
- 목적함수는 원본 규약의 **F1(positive=1=비독성)**으로 수정했다. 원본 라벨을 사용하는 캐시를 확인했으므로 이번 경로에서 추가 반전하지 않는다.
- 클로드가 보고한 최고 F1 0.834178은 비독성 비율 59%의 값이다. 실제 1차 파일은 57.7%이며, 저장된 가중치로 재계산한 해당 OOF F1은 **0.832140**다. 가중치가 소수 3자리로 저장되어 미세한 오차가 있다.
- `submission_meta.json`의 `oof_at_chosen`은 스캔 간격에 0.577이 없어 비어 있었다. `blend_oof_prob.npy`도 이전 블렌드 캐시여서 이번 비교에서는 실제 1차 생성에 사용한 모델과 가중치로 다시 계산했다.
- 입체를 무시하면 같은 연결구조인 train/predict 81건을 라벨 복사하지 않는 정책을 유지했다. 제출 SMILES 원문과 순서는 변경하지 않았다.

## 적용한 기법과 선택

1. 기존 9,305개 입력을 재사용했다. LightGBM 8개 설정의 잎 수·최소 샘플·특징 샘플링·L1/L2·path smoothing·extra trees를 공통 2개 fold로 먼저 비교하고 상위 3개를 전체 5-fold로 학습했다.
2. chiral radius-3 count-Morgan 2,048개와 feature-Morgan count 1,024개를 추가 학습했다. XGBoost의 깊이·child weight·샘플링·규제도 비교했다.
3. ECFP/FCFP/count-Morgan/RDKitFP Tanimoto 복합 SVM과 물성 RBF kernel 15% 결합을 비교했다. 물성 표준화는 각 학습 fold에서만 맞췄다. SVM의 sigmoid 점수는 보정된 확률이 아니다.
4. LightGBM 상위 2개는 seed 42와 2026의 5-fold 예측을 평균했다. 분할 변동을 줄이는 효과가 있었고, 평균 OOF가 메타 입력에 반영된다.
5. convex blend, AUC/F1 greedy blend, 규제 로지스틱 스태킹, 물성·골격 공유 여부와의 상호작용 스태킹을 비교했다. 가장 높은 임계값 교차검증 F1을 낸 **logistic_C0.1**을 선택했다. 상호작용 모델은 최종 선택되지 않았다.
6. F1 최고값에서 0.0005 이내인 임계값 구간과 fold별 임계값의 중앙값을 사용했다. 최종 cutoff는 **0.402088**다. 테스트 양성 비율을 강제로 맞추지 않았다.

## 보조 검증

같은 연결구조의 입체이성질체를 동일 fold에 묶은 그룹 CV에서 신규 LightGBM의 AUC는 **0.88992**, 비독성 F1은 **0.83103**였다. 서로 다른 골격을 분리한 검증과는 구분한다. [그룹 검증](connected_group_cv.json), [반복 CV](repeat_cv_results.csv).

새 파일의 컬럼명·927행·SMILES 원문과 순서·0/1 값·모델 예측 일치를 검증했다. 기존 데이터·클로드 코드와 캐시·1차 파일의 SHA-256도 동일하다. 선택한 스태킹은 저장된 입력으로 다시 실행해 OOF와 927개 예측이 일치함을 확인했다.
