## 재실행

노트북은 `04_노트북` 또는 미니프로젝트 폴더에서 열고 위에서 아래로 실행한다. 첫 셀이 프로젝트 위치를 찾는다. Python 환경은 작업공간의 `.venv_eda`를 사용한다. 현재 노트북은 이 폴더의 원본·진단표·중간 결과·스크립트를 함께 읽는다.

분석 스크립트는 **미니프로젝트 폴더에서** 다음과 같이 실행한다.

```sh
../.venv_eda/bin/python 03_분석/스크립트/run_stereo_eda.py --self-check
../.venv_eda/bin/python 03_분석/스크립트/run_stereo_eda.py
../.venv_eda/bin/python 03_분석/스크립트/make_compact_eda.py
```

두 분석 스크립트는 각각 탐색126열/축소8열과 CIP-Morgan 실험 결과를 갱신한다. 최종 표준 Morgan+8 파일 생성은 노트북이 담당한다. 원본 백업과 train.csv는 변경하지 않는다.

## 정리 기록

2026-10-02에 용도별로 이동했다. 기존 파일은 삭제하지 않았다. 데이터·PPT·PDF·이미지는 이동 전후 SHA-256이 동일한지 확인했다. 실행 경로를 수정한 코드·노트북·문서는 `03_분석/검증기록/정리전_경로파일`에 수정 전 사본을 보관했다. 파일별 이전/현재 위치는 [이동 기록](03_분석/검증기록/폴더정리_이동기록.json)에 있다.

정리 후 노트북 전체10개 코드 셀을 임시 출력 폴더에서 실행했다. 재생성한 최종 CSV의 SHA-256이 기존 최종 파일과 동일했고, label충돌0건을 확인했다. 두 분석 스크립트의 import와 입체정보 기본 검증, 문서 상대링크도 통과했다. [정리 검증 결과](03_분석/검증기록/폴더정리_검증.json).
