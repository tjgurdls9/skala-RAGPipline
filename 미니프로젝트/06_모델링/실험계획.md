# 독성 분류 모델링 계획 · 2026-10-02

- 목표: 927행의 독성 예측을 제출 형식 SMILES,output으로 생성한다. 원본 템플릿 및 기존 데이터는 변경하지 않는다.
- label: 학습 파일 1=독성, 0=비독성. 과제 PDF 13·15쪽 제출값 1=비독성, 0=독성. 제출 시 1-학습예측을 적용한다.
- 분리: Bemis–Murcko 골격(입체 무시)이 같은 행은 같은 그룹. 무고리 분자는 ACYCLIC 그룹. seed=42, 5분할 첫 fold를 최종 평가로 잠그고 나머지에서 4분할 그룹 교차검증한다.
- 선택: 개발 데이터 OOF ROC-AUC로 모델을 선택한다. 후보 상위 3개 단순 평균도 비교하며 AUC가 단일 최상위보다 0.002 이상 좋아야 채택한다. 임계값은 개발 OOF macro-F1을 최대화하는 0.15~0.85 구간에서 선정한다. 동률은 0.5에 가까운 값을 선택한다.
- 지표: ROC-AUC, PR-AUC, Accuracy, 양쪽 클래스 Precision/Recall/F1, macro-F1, Specificity, 혼동행렬, Brier score. 최종 평가는 선택/임계값 고정 후 한 번 수행한다.
- 후보: 기존 fingerprint 로지스틱 회귀 기준선, 재생성 Morgan+FCFP+PTFP+물성+전역 입체3변수 기반 로지스틱/RF/ExtraTrees/LightGBM/SVM. 다수 클래스 Dummy 기준선도 포함한다.
- 기존 8변수 중 국소5개는 전체 데이터 label 충돌을 보고 선정했다. +8 모델은 탐색 비교로만 기록하고 최종 모델 선택에서 제외한다. 전역3개 및 Morgan은 label을 읽지 않고 계산한다. 상수 제거의 전체 데이터 사용은 비지도이나 이력에 명시한다.
- 확인: 모든 8349행의 Morgan 및 입체8개 재계산을 기존 최종 데이터와 대조한다. 각 fold의 골격/연결구조 중복0건을 assert한다. 제출의 컬럼·행순서·SMILES·0/1·원본 hash를 검증한다.
- 제한: 기존 EDA가 전체 label을 보았으므로 완전한 외부 검증이 아니다. 골격 분리는 유사성 전체를 차단하지 않는다. 실험조건·용량·독성 endpoint의 원자료 정의는 미확인이다. 계산확률은 의료적 안전성 또는 보정된 독성확률의 증명이 아니다.
- 결과: 실행 스크립트, 실행 결과 포함 모델링 노트북, 비교/평가/오류/예측진단 표, 그래프, 전체 학습 모델, 새 제출 CSV. 실패 시 원본을 그대로 사용할 수 있다.
