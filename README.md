# SKALA 독성 데이터 분석 프로젝트

기존 RAG 작업 폴더에 보관하던 독성 EDA·모델링·발표·예측 결과 프로젝트입니다.

`미니프로젝트/README.md`에서 사용할 데이터·직접 작성한 분석 코드·노트북·최종 예측·보고서를 확인합니다. 분석은 미니프로젝트 README의 실행 위치와 `06_모델링/requirements-modeling.txt`를 따릅니다.

번호별 분석 경로는 재현 스크립트가 참조하므로 유지합니다. 교재·실습 가이드·RAG 예제 노트북·참고 논문·수업용 판례 및 관광 자료는 로컬에 보존하고 업로드하지 않습니다. 가상환경·API 키·임베딩/LLM 캐시·학습 모델·NumPy 중간 캐시도 제외합니다.
